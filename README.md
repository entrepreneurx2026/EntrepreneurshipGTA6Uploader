# Entrepreneurship GTA 6 Uploader

A private tool used only by the owner of the GTA 6 YouTube channel (Entrepreneurship 2026). It uploads and schedules the channel's own Shorts, adds them to the channel's playlists and updates their titles and descriptions through the YouTube Data API. It is not offered to the public and nobody else can sign in to it.

Contact: entrepreneurx2026@gmail.com

## Privacy policy

- The app signs in only to the channel owner's own Google account (entrepreneurx2026@gmail.com).
- It uses Google user data only to upload, schedule and manage videos, playlists and comments on that one channel.
- It does not sell, share or transfer any Google user data to anyone, and does not use it for advertising.
- Sign-in tokens are kept in a private file with restricted access in the owner's own workspace and are never published.
- No data is collected from viewers or other users.
- The owner can remove access at any time at https://myaccount.google.com/permissions
- Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
